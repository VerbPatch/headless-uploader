# Azure Integration

Uploading files to Azure Blob Storage is straightforward using Headless Uploader's `createAzureAdapter`. This adapter is optimized for Azure's specific requirements, such as Shared Access Signature (SAS) tokens and mandatory blob-type headers.

## The SAS Token Workflow

For security, your client-side application should use temporary Shared Access Signature (SAS) URLs generated by your backend:

1. **Request SAS**: Your frontend asks your backend for a SAS URL for a specific blob.
2. **Generate SAS**: Your backend uses the Azure Storage SDK to generate a SAS URL with `Write` permissions.
3. **Upload**: Your frontend uses Headless Uploader to send the file directly to Azure.

## Implementation

<CodeBlock>
```typescript
import { useUploader, createAzureAdapter } from '@verbpatch/headless-uploader';

const azureAdapter = createAzureAdapter({
  async getUploadUrl(file) {
    // 1. Call your backend to get the SAS URL
    const response = await fetch('/api/azure/generate-sas', {
      method: 'POST',
      body: JSON.stringify({
        blobName: file.metadata.name,
      }),
    });
    
    const { sasUrl } = await response.json();
    return sasUrl;
  },
  // Optional: defaults to 'BlockBlob'
  blobType: 'BlockBlob', 
});

const uploader = useUploader({
  protocol: 'cloud',
  cloudAdapter: azureAdapter,
  onUploadSuccess: (file, response) => {
    console.log('File uploaded to Azure:', file.metadata.name);
  },
});
```
</CodeBlock>

## Azure Specific Headers

The Azure adapter automatically adds the `x-ms-blob-type` header, which is required by Azure for `PUT` operations. You can add additional headers (like `x-ms-meta-*`) via the `headers` option in `AzureAdapterOptions`.

<CodeBlock>
```typescript
const azureAdapter = createAzureAdapter({
  getUploadUrl: mySasFunction,
  headers: {
    'x-ms-meta-uploadedby': 'HeadlessUploader',
  }
});
```
</CodeBlock>
