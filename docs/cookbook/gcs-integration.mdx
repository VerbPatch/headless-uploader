# Google Cloud Storage Integration

Uploading files to Google Cloud Storage (GCS) is simple with the `createGCSAdapter`. Like other cloud providers, GCS uses a Signed URL mechanism for secure client-side uploads.

## The Signed URL Workflow

Secure your uploads by using temporary Signed URLs generated by your server:

1. **Request URL**: Your frontend asks your backend for a Signed URL.
2. **Generate URL**: Your backend uses the Google Cloud SDK to create a URL for a `PUT` request.
3. **Upload**: Headless Uploader sends the file binary directly to GCS.

## Implementation

<CodeBlock>
```typescript
import { useUploader, createGCSAdapter } from '@verbpatch/headless-uploader';

const gcsAdapter = createGCSAdapter({
  async getUploadUrl(file) {
    // 1. Call your backend to get the Signed URL
    const response = await fetch('/api/gcs/generate-signed-url', {
      method: 'POST',
      body: JSON.stringify({
        name: file.metadata.name,
        contentType: file.metadata.type,
      }),
    });
    
    const { url } = await response.json();
    return url;
  }
});

const uploader = useUploader({
  protocol: 'cloud',
  cloudAdapter: gcsAdapter,
  onUploadSuccess: (file, response) => {
    console.log('Successfully uploaded to GCS');
  },
});
```
</CodeBlock>

## CORS Configuration

For GCS uploads to work from a browser, you must configure CORS on your GCS bucket. You can do this using the `gsutil` CLI:

<CodeBlock>
```json
// cors-json-file.json
[
  {
    "origin": ["https://your-app-domain.com"],
    "method": ["PUT"],
    "responseHeader": ["Content-Type", "x-goog-meta-custom"],
    "maxAgeSeconds": 3600
  }
]
```
</CodeBlock>

Then apply it:
`gsutil cors set cors-json-file.json gs://your-bucket-name`
