# Uploader Options

Headless Uploader is highly configurable. You can pass an options object to `useUploader` to customize its behavior.

## Events

Headless Uploader provides a rich set of lifecycle callbacks:

* `onFilesAdded`: Fired when files are successfully added.
* `onFilesRejected`: Fired when files fail validation.
* `onUploadStart`: Fired when an individual file starts uploading.
* `onUploadProgress`: Fired periodically with progress updates.
* `onUploadSuccess`: Fired when an upload completes successfully.
* `onUploadError`: Fired when an upload fails.
* `onAllComplete`: Fired when the entire queue is processed.
