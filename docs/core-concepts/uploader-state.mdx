# Uploader State

Headless Uploader maintains a reactive state that allows you to easily build informative UIs. This state is updated automatically as files move through the upload lifecycle.

## Accessing State

You can access the current state using the `getState()` method from the uploader instance:

<CodeBlock>
```typescript
const state = uploader.getState();
```
</CodeBlock>

In framework-specific wrappers like React or Vue, this state is automatically reactive, so your UI will re-render whenever it changes.

## The UploadFile Object

Each file in the `files` array is represented by an `UploadFile` object, which provides detailed information:

<table>
  <thead>
    <tr>
      <th>Property</th>
      <th>Type</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>`id`</td>
      <td>`string`</td>
      <td>A unique identifier for the file.</td>
    </tr>
    <tr>
      <td>`file`</td>
      <td>`File`</td>

    </tr>
    <tr>
      <td>`metadata`</td>
      <td>`FileMetadata`</td>

    </tr>
    <tr>
      <td>`status`</td>
      <td>`UploadStatus`</td>

    </tr>
    <tr>
      <td>`progress`</td>
      <td>`UploadProgress`</td>
      <td>Real-time progress stats for this specific file.</td>
    </tr>
    <tr>
      <td>`preview`</td>
      <td>`string`</td>
      <td>A data URL or blob URL for the file's preview (if enabled).</td>
    </tr>
    <tr>
      <td>`error`</td>
      <td>`Error`</td>
      <td>The error object if the upload failed.</td>
    </tr>
  </tbody>
</table>

## Progress Metrics

The `totalProgress` and `file.progress` objects provide several useful metrics:

* `percentage`: The current completion percentage (0-100).
* `loaded`: The number of bytes transferred so far.
* `total`: The total size of the file(s) in bytes.
* `speed`: Current transfer speed in bytes per second.
* `timeRemaining`: Estimated seconds until completion.
