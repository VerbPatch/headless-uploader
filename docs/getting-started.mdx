# Getting Started

This guide will help you quickly integrate Headless Uploader into your project. While the core library is framework-agnostic, we'll demonstrate a basic setup using each framework we support to illustrate the workflow.

## 1. Installation

First, install the wrapper for your chosen framework.

    # Using npm

    # Using yarn
    yarn add @verbpatch/react-uploader

    # Using pnpm
